# Portfolio Content Review

## Scope

This review updates portfolio copy only. Layouts, imagery, links, animations, project order, and interaction behavior were not changed.

## Major revisions

| Area | Before | Revised approach |
| --- | --- | --- |
| Profile | Broad claims about modern digital products | First-person introduction focused on practical applications, full-stack work, and AI-integrated projects. |
| Work intro | “Built to work. Designed to matter.” | “Projects I've built. For real use cases.” |
| Experience | “Where I've been & what's next.” | “Experience & education.” |
| LMS | Abstract labels such as “Beyond the dashboard” | Specific labels for the admin dashboard, courses, batches, lessons, and backup workflows. |
| CinnamonCare | Editorial slogans such as “From image to insight” | Direct headings for AI disease detection, maps, related products, and project contribution. |
| Liya Savi | Marketing-oriented marketplace copy | Direct explanation of storefronts, product discovery, and admin management. |
| NKS Clothing | Fashion-oriented slogans | Clear descriptions of the storefront, product details, product management, stock, and returns. |
| Contact | “Let’s build something meaningful.” | “Let’s talk about your project.” |

## Copy principles applied

- Replaced broad marketing language with specific features and responsibilities.
- Used first person in personal profile content; project copy remains factual and feature-focused.
- Shortened captions where possible: for example, “Product Catalogue”, “Product Details”, and “Admin Dashboard”.
- Preserved approved Hero, About, and Story signature text because those are animation-sensitive.
- Preserved factual roles, project statuses, education, employment information, URLs, and screenshots.

## Animation-sensitive text

- The Hero and About signature headlines were not changed.
- Project headings were updated only within existing elements and line-break structures, so the existing GSAP selectors and layout patterns remain intact.

## Remaining review notes

- Current CinnamonCare source screenshots may contain names, email addresses, order details, or financial figures in admin views. They were left unchanged as requested and should be reviewed before publication.
- The content pass does not include live iPhone Safari testing.
